# Roadmap

## Done

- 0.3.0 — Structural layer (PageHeader, Modal, `hub-panel--padded`, z-index
  tokens, scroll rule), added under the park simplicity directive: the DS
  ships only what removes work for the AI — one structure, one set of
  classes, four rules.

## Near Term

- Stabilize the public GitHub release workflow.
- Keep the README and demo aligned with the public package surface.
- Keep the Hub-served runtime contract documented as the production path.
- Tighten performance budgets after the first production consumer.

## Next

- Expand component coverage only when it removes work for the AI and the API
  remains coherent — expansion is a cost before it is a feature.
- Add framework-agnostic usage examples beyond React where justified.
- Improve automated verification around packed artifacts and demo smoke checks.

## Non Goals For Now

- A large component catalog without clear design constraints.
- Runtime theming systems outside the Hub manifest/sync contract.
- Multiple parallel production distribution models with undocumented differences.
